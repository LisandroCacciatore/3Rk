# SaaS & Enterprise Behavioral Design

SaaS gamification must focus on **efficiency, mastery, collaboration, and value realization**, never juvenile points or distraction.

## Phase Architecture for SaaS

### Phase 1: Discovery & Onboarding (Time to Value)
- **Goal:** Minimize time to "Aha! Moment".
- **Primary Drives:** CD2 (Competence), CD3 (Feedback), CD7 (Curiosity).
- **Mechanics:**
  - Progress Bar with high initial completion (e.g., 30% pre-filled upon account creation).
  - Empty-state visual guides (Desert Oasis).
  - Immediate win-states upon completing first core setup task.

### Phase 2: Scaffolding (Habit Formation & Workflow Integration)
- **Goal:** Integrate SaaS tool into daily/weekly operational habits.
- **Primary Drives:** CD4 (Ownership), CD2 (Progress), CD5 (Team Integration).
- **Mechanics:**
  - **The Alfred Effect (CD4):** Custom views, saved filters, automated templates that make switching software painful.
  - **Group Alignment (CD5):** Team activity feeds, shared dashboards, cross-departmental handoffs.

### Phase 3: Endgame (Power User Mastery & Advocacy)
- **Goal:** Retain veteran users and convert them into champions/trainers.
- **Primary Drives:** CD3 (Autonomy/Creativity), CD5 (Status/Mentorship), CD1 (Community Impact).
- **Mechanics:**
  - Advanced shortcut customization / API access / Macro building (CD3).
  - Admin/Power-user distinction and internal community leadership roles (CD5).

## SaaS Anti-Patterns

- **Vanity Metrics as Progress:** Showing "total logins" or "actions completed" as achievement (CD2) when the user hasn't achieved meaningful outcomes.
- **Feature Flood:** Releasing 40 features without onboarding depth, causing choice paralysis (CD3 overload without CD2 scaffolding).
- **Dashboard Cemetery:** Building analytics dashboards nobody opens because they report data without insight or actionability (CD7 without CD3).
