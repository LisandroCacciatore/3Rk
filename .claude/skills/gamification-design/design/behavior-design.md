# Behavior Design Pipeline

Never translate a business goal directly into a game mechanic. Business goals describe organizational needs; behavioral design creates human motivation.

## Conversion Pipeline

Business Goal
│
▼
User Outcome
│
▼
Desired Behavior
│
▼
Emotional Motivation
│
▼
Core Drive Selection
│
▼
Mechanic & Feedback Design
│
▼
Progression & Habit Formation

---

## Pipeline Execution Steps

### Step 1: Identify Business Goal
State the organizational objective quantitatively.
*Example:* Increase 30-day retention in an enterprise analytics tool.

### Step 2: Define User Outcome
Translate the business goal into a valuable real-world benefit for the user.
*Example:* User consistently catches performance bottlenecks before they affect production.

### Step 3: Define Desired Behavior
Specify the exact, granular action the user must perform. Must be observable and unambiguous.
*Incorrect:* "User uses analytics more."
*Correct:* "User reviews performance anomaly reports every Monday morning and approves optimization suggestions."

### Step 4: Map Emotional Motivation
Identify what the user wants to feel when performing this behavior.
*Example:* Feels smart, competent, proactive, and ahead of potential failures.

### Step 5: Select Core Drives
Choose 1–3 Core Drives that align with the target emotion.
- **Primary:** CD2 (Accomplishment — solving bottlenecks).
- **Secondary:** CD3 (Empowerment — choosing optimization strategies).
- **Tertiary:** CD4 (Ownership — maintaining a clean system profile).

### Step 6: Select Mechanics & Feedback
Choose mechanics that activate the selected Core Drives without creating unwanted side effects.
- *Mechanic:* Weekly Anomaly Summary with interactive strategy toggles.
- *Feedback:* Visual impact calculation ("Saved 12 hours of processing time").

### Step 7: Risk Analysis & Metric Check
- **Risk:** Does this reward proxy behavior (opening the app) instead of actual value creation (resolving issues)?
- **Metric:** Track percentage of flagged anomalies resolved vs. raw logins.
